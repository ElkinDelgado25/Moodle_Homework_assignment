# Recursos visuales del README

`header.svg` reproduce las letras y los colores del panel de `src/moodle_tasks/ui.py`. No incluye datos de cuentas. Los banners `*-section.svg` combinan los logos indicados abajo con el diseño del proyecto.

Los logos identifican las plataformas; no implican afiliación ni respaldo al proyecto.

- Debian, Arch Linux, Apple, Anthropic, Cursor, Google y GitHub Copilot: [Simple Icons](https://github.com/simple-icons/simple-icons), licencia [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Colores adaptados para el README. Las marcas conservan los derechos de sus titulares.
- Codex: simbolo de OpenAI obtenido desde [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg). El archivo se indica como dominio publico; la marca OpenAI pertenece a su titular.
- Windows 11: [Devicon](https://github.com/devicons/devicon/blob/master/icons/windows11/windows11-original.svg), licencia [MIT](https://github.com/devicons/devicon/blob/master/LICENSE). Consulta `DEVICON-LICENSE.txt` para el aviso de licencia.
